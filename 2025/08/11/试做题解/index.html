🧠 思路分析

🔍 第一步：理解题目本质

首先，这是一个非常经典的嵌套函数题目。题目的核心思想非常简单：

用一个通用化的函数，再套用所需要的特定函数和数值，最终输出我们想要的结果。

我们都知道，函数由变量和变换过程组成。

📝 第二步：确定函数结构

对于第一步，我们知道需要定义一个内部函数：

def count(n):
    # 这里需要计数的逻辑

这个函数的作用是：在n这个整数条件下，计数并输出满足条件的数的个数。

📌 注意：此时还没有体现出要使用的子函数！

🔄 第三步：设计计数逻辑

然后，我们要思考如何对输入的数进行计数，并输出我们想要的结果。

题目中的例子说明了：输入一个数，我们要计算它的所有正因数。

📝 以12为例：12的正因数为 1, 2, 3, 4, 6, 12，共6个。

🛠️ 代码实现过程

💡 初步思路

我们需要：

  1. 一个统计计数器 count，初始值为 0
  2. 一个遍历变量 i，用来遍历从 1 到 n 之间的所有数
count, i = 0, 1

⚠️ 第一次尝试（有错误）

while i <= n:
    if i = condition(n):  # ❌ 这里有问题！
        count = count + 1
    i = i + 1
return count

🔧 发现问题并修正

问题在于：我们怎么判断这个 i 符合我们要的条件？

应该要用布尔逻辑！

  • 如果 condition 函数返回 True，就满足 if 条件，count 就能 +1
  • 反之，如果返回 False，就不能 +1

所以正确的写法是：

if condition(n, i):  # ✅ 正确！

只要 i 和 n 满足 condition，就能实现题目想要的功能。

🎆 最终解答

💫 完整代码实现

def count_cond(condition):
    def count(n):
        count_num, i = 0, 1
        while i <= n:
            if condition(n, i):
                count_num = count_num + 1
            i = i + 1
        return count_num
    return count
