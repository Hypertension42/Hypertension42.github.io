🚀 快速上手指南

📝 创建新文章

$ hexo new "我的新文章"

详细说明：

  • 这个命令会在 source/_posts/ 目录下创建一个新的Markdown文件
  • 文件名会基于标题自动生成
  • 自动包含基本的Front Matter配置

📖 更多信息: 写作文档

🖥️ 启动本地服务器

$ hexo server

功能特性：

  • ✅ 实时预览您的博客
  • ✅ 热重载 - 修改文件后自动刷新
  • ✅ 默认运行在 http://localhost:4000
  • ✅ 支持草稿预览

📖 更多信息: 服务器文档

🔨 生成静态文件

$ hexo generate

生成内容：

  • 📁 将Markdown文件转换为HTML
  • 🎨 应用主题样式和布局
  • ⚡ 优化资源文件
  • 📦 输出到 public/ 目录

📖 更多信息: 生成文档

🌐 部署到远程站点

$ hexo deploy

支持的部署平台：

  • 🔷 GitHub Pages - 免费静态网站托管
  • 🔶 Netlify - 现代化的部署平台
  • 🔴 Vercel - 快速的全球CDN
  • ⚫ Heroku - 云应用平台

📖 更多信息: 部署文档

💡 进阶技巧

🎯 常用命令组合

# 清理缓存并重新生成
$ hexo clean && hexo generate

# 生成并启动服务器
$ hexo generate && hexo server

# 一键部署流程
$ hexo clean && hexo generate && hexo deploy
